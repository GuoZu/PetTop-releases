# PetTop 更新檔

此公開儲存庫僅提供 PetTop 桌面程式的安裝檔、版本資訊與更新說明，不存放應用程式原始碼或使用者寵物資料。

## 更新方式

PetTop 0.2.1 起支援偵測新版，再讓使用者下載、手動安裝。程式會查詢本儲存庫最新的正式 Release；有新版時，設定頁提供「前往下載新版」。不會自動下載、執行安裝或重新啟動。

請依電腦選擇安裝檔：

- Apple 晶片 Mac：`mac-arm64.dmg`
- Intel Mac：`mac-x64.dmg`
- Windows 64 位元：`win-x64.exe`；如提供 ZIP，也可使用免安裝版。

下載後先結束 PetTop，再安裝或替換程式。寵物與成長紀錄保留在本機；建議更新前使用內建的完整備份。

安裝檔不要求簽章或公證，系統可能顯示來源提示。原本 0.1.0／0.2.0 需先手動安裝具備新版檢查功能的版本。

目前尚未公開正式 Release。安裝檔準備完成後會提供於 [Releases](https://github.com/GuoZu/PetTop-releases/releases)，並附上 `SHA256SUMS.txt`。
